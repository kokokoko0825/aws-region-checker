# Region Checker for AWS Console

AWS マネジメントコンソールで、いま操作しているリージョンを入力するまで消えないバナーを表示するブラウザ拡張です。リージョンを取り違えたまま作業する事故を減らすことを目的にしています。

> **非公式の拡張です。** Amazon Web Services, Inc. およびその関連会社とは無関係で、提供・承認・サポートを受けていません。「AWS」「Amazon Web Services」は Amazon.com, Inc. またはその関連会社の商標です。

## 動作

- リージョンボタンの隣に「現在のリージョン: ap-northeast-1 / 消すにはリージョンを入力」と入力欄を表示します。
- 入力欄に現在のリージョンコードを入力するとバナーが消えます(大文字小文字は区別しません)。
- そのタブで最後に確認したリージョンと、現在のリージョンが違えば再表示します。覚えているのはタブごとに直近の 1 件だけなので、前に確認したリージョンへ戻ったときも再表示します。
  - 例: 東京で `ap-northeast-1` を入力 → 消える → `us-east-1` に切替 → 再表示 → `us-east-1` を入力 → 消える → 同じタブで東京に戻る → 再表示
  - 再表示されたバナーを消さずに、最後に確認したリージョンへ戻った場合は表示しません(例: 上の最後で東京を入力せず `us-east-1` に戻る)。
  - 別のタブの確認状態には影響しません。新しいタブ・複製したタブでは最初から表示します。
- IAM / CloudFront / Route 53 などのグローバルサービスでは「Global」と表示します。消すには `Global` と入力します。
- リージョンボタンが見つからないページでは、画面右上に固定表示します。

確認済みのリージョンは、拡張側の `chrome.storage.session`(メモリ上のみ、ディスクには書かれない)にタブごとに 1 件保存します。タブを閉じるとそのタブの分を削除し、ブラウザの終了、拡張の無効化・再読み込み・更新で全件消えます。保存や読み出しに失敗した場合は、確認済みなしとして扱いバナーを表示します。

## インストール

ビルドは不要です。このリポジトリを clone またはダウンロードして、フォルダをそのまま読み込みます。

### Chrome / Edge

1. `chrome://extensions`(Edge は `edge://extensions`)を開く
2. 右上の「デベロッパー モード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」を押し、このフォルダを選ぶ

### Firefox(127 以降)

1. `about:debugging#/runtime/this-firefox` を開く
2. 「一時的なアドオンを読み込む」を押し、このフォルダの `manifest.json` を選ぶ

一時的なアドオンは Firefox を終了すると解除されます。

## 権限とプライバシー

- 動作対象は `https://*.console.aws.amazon.com/*` のみです。`host_permissions` は要求しません。
- `permissions` は `storage` のみです。コンソールはリージョンごとに URL のオリジンが変わるため、ページ側の `sessionStorage` では「このタブで最後に確認したリージョン」をリージョンをまたいで持てません。拡張側の `chrome.storage.session` に置くために `storage` 権限を使います。`tabs` 権限は使わず、タブの URL やタイトルは取得しません。
- 外部との通信は行いません。
- アカウント ID、ユーザー名、Cookie などの認証情報・アカウント情報は読みません。参照するのは URL のホスト名・パス・`region` クエリと、リージョンボタンの表示テキストだけです。
- 保存するのは、タブごとの確認済みリージョンコード(または `Global`)1 件だけです(`chrome.storage.session`、キーはブラウザが割り振るタブ番号)。

## 制限

- リージョンを意識させるための表示であり、誤操作を防止・保証するものではありません。
- コンソールの DOM 構造に依存する部分は、AWS 側の変更で動かなくなることがあります。
- GovCloud / 中国リージョンのコンソール(別ドメイン)は対象外です。
